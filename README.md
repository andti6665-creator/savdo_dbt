# Savdo DB — Vizual Panel va SQL Baza

`savdo_db` ma'lumotlar bazasi (`buyurtmalar`, `buyurtma_qatorlari`, `mahsulotlar`, `kategoriyalar`, `mijozlar`), ko'rinishlar (`v_omborda_bor`, `v_buyurtma_tafsilot`, `v_kunlik_savdo`, `v_mahsulot_kategoriya`) va `sp_v_mk_insert` protsedurasi asosidagi vizual boshqaruv paneli.

## Fayllar
- `index.html` — Bosh sahifa (vizual boshqaruv paneli)
- `robots.txt` — Google qidiruv tizimi uchun qoidalar
- `sitemap.xml` — Sayt xaritasi
- `README.md` — Loyiha tavsifi

## GitHub Pages orqali ishga tushirish
1. Repozitoriy **Settings -> Pages** bo'limiga kiring.
2. **Branch** sifatida `main` va `/ (root)` ni tanlab **Save** bosing.
3. Sayt manzili: `https://USERNAME.github.io/savdo-db/`
